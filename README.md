# Nithin S | Creative Developer Portfolio

A responsive, brutalist-styled developer portfolio with a signature white & violet theme, featuring smooth micro-animations, Lucide icons, and integrated form submissions powered by Web3Forms.

## Features
- **Brutalist Sticky Header & Responsive Navigation**
- **Geometric Split-Screen Hero Card**
- **Intersection Observer** active link indicators and reveal animations
- **Responsive Layout** (optimised for mobile, tablet, and desktop views)
- **Functional Contact Form** integrated with Web3Forms (delivers directly to bunnynithin2288h@gmail.com)

## Tech Stack
- HTML5 & CSS3 (Custom Variables)
- Vanilla Javascript
- Lucide Icons
- Web3Forms API
